# Personal Expense Tracker CLI

A interactive Command Line Interface (CLI) application to record, manage, and summarize personal finances with local persistent storage.

## Features
- Add expenses with categories, descriptions, and timestamps.
- View detailed historical list of all transactions.
- Automated breakdown and percentage summary by spending category.
- Persistent local JSON data persistence (`expenses.json`).

## Requirements
- Python 3.6+

## Quick Start
```bash
python expense_tracker.py
```
